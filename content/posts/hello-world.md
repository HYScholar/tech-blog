## 🎉 博客上线！

这是团队技术博客的第一篇文章。该博客基于 **Hugo** 静态站点生成器构建，托管在 **GitHub Pages** 上，通过 GitHub Actions 自动部署。

### 技术栈

- **静态生成**: Hugo
- **托管**: GitHub Pages
- **CI/CD**: GitHub Actions
- **版本管理**: Git + GitHub PR

### 如何发布文章

1. 在 `content/posts/` 目录下创建 Markdown 文件
2. 添加 frontmatter（title、date、tags、author）
3. 提交 Pull Request
4. 合并到 `main` 分支后自动部署 🚀

### 文章格式

```markdown
---
title: "文章标题"
date: "2026-07-12"
tags: ["标签1", "标签2"]
author: "作者名"
---

文章内容...
```
